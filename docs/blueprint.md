# **App Name**: DocuFlow

## Core Features:

- Draft Document Creation: Users can create documents with text and images, saving them as drafts.
- Document Submission: Users can submit documents for approval, selecting another user as the reviewer. The document becomes uneditable during review.
- Review Notifications: Reviewers receive notifications for pending documents, with direct access to the review page.
- Approval Workflow: Approved documents are published; rejected documents are returned with the reviewer's feedback.
- Admin Management: Administrators manage all documents and statuses, with access to edit and approval histories, including the ability to reassign reviewers. Logging will be used extensively.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to evoke trust and clarity in document management.
- Background color: Light gray (#F0F4F8), providing a neutral backdrop that ensures readability and focuses attention on content.
- Accent color: Muted teal (#4DB6AC), used to highlight important actions such as approval or submission, providing a clear visual cue.
- Clean and professional typography for readability and a modern feel.
- Consistent and intuitive icons to represent document actions and statuses.
- Well-organized layout with clear visual hierarchy for efficient document management.
